# Semantic HTML5 Structure and Accessible Forms

This project demonstrates a clean, semantic HTML5 website layout with a focus on accessibility, proper form handling, and organized content structure. It includes three pages: **Home**, **Contact**, and **Miscellaneous**, each built using semantic elements and best practices.

## Folder Structure
source/ ├── index.html ├── pages/ │ ├── contact.html │ └── misc.html ├── assets/ │ └── img/ │ ├── welcome.jpg │ ├── contact.jpg │ └── dawg.jpg


## Pages Overview

### Home (`index.html`)
- Introduces the site and its purpose
- Highlights semantic HTML benefits
- Includes a welcome image (`welcome.jpg`)
- Navigation links to Contact and Miscellaneous pages

### Contact (`pages/contact.html`)
- Accessible contact form with labels, fieldsets, and required fields
- Includes a contact illustration (`contact.jpg`)
- Uses semantic structure for layout and form grouping

### Miscellaneous (`pages/misc.html`)
- Fun content section featuring "What the dawg doin"
- Includes an image (`dawg.jpg`)
- Styled consistently with other pages

## Accessibility Features
- "Skip to main content" link for screen readers
- Semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- Clear form labels and input associations

## Styling
- Unified layout using internal CSS
- Responsive and readable typography
- Accessible focus outlines and navigation cues

## How to Run
1. Clone or download the project folder
2. Open `index.html` in your browser
3. Navigate between pages using the site’s navigation links
